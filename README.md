# MINERVA
AI-Powered Investigative Network Intelligence Platform

## Overview

MINERVA is an AI-powered investigative network intelligence platform that
uses NLP, knowledge graphs, and graph analytics to uncover and explain
potential connections across people, cases, vehicles, phones, and locations.

## Current Features

- AI-based entity extraction
- Relationship extraction
- Neo4j knowledge graph
- Person search
- Interactive network visualization
- Hidden connection / shortest path detection
- FastAPI backend
- Streamlit dashboard

## Tech Stack

- Python
- spaCy
- Neo4j
- FastAPI
- Streamlit
- PyVis
